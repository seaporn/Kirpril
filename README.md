# Мои смены

Компактное приложение для учета смен и зарплаты.

## Что умеет

- кнопка **Смена окончена** для быстрого ввода времени;
- начало смены по умолчанию: **10:00**;
- окончание смены подставляется по текущему времени;
- расчет суммы за смену, месяц и весь период;
- календарь показывает дату и сумму в каждой заполненной ячейке;
- выходные выделены красным;
- данные сохраняются в браузере через localStorage;
- можно загрузить график из Excel, CSV или JSON;
- можно сохранить и загрузить резервную копию.

## Загрузка на GitHub Pages

Загружай в репозиторий файлы из папки проекта, а не сам zip:

- `index.html`
- `styles.css`
- `app.js`
- `manifest.webmanifest`
- `service-worker.js`
- `README.md`

Потом включи GitHub Pages: **Settings → Pages → Deploy from a branch → main → /root → Save**.
