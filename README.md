# Мои смены

Компактное приложение для учета смен и зарплаты.

## Что внутри

- главная кнопка **«Смена окончена»**;
- приложение не масштабируется на телефоне;
- всплывающие окна фиксированного размера и не прыгают;
- компактные поля времени: **Начал** и **Закончил**;
- начало по умолчанию всегда **10:00**;
- конец по умолчанию — текущее время;
- расчет суммы за смену, месяц и весь период;
- календарь с отметками и список смен за месяц;
- загрузка графика из `.xlsx`, `.xls`, `.csv`, `.json`;
- сохранение данных в браузере.

## Как загрузить на GitHub Pages

1. Распаковать zip.
2. Загрузить все файлы из папки в репозиторий:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `manifest.webmanifest`
   - `service-worker.js`
   - `README.md`
3. Включить GitHub Pages: `Settings → Pages → Deploy from a branch → main → /root`.

## Важно

Лучше заменять все файлы полностью. В этой версии изменены `index.html`, `styles.css`, `app.js`, `service-worker.js`, `README.md`.
