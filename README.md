# Мои смены

Компактное приложение для учёта смен и зарплаты.

## Что изменено в этой версии

- Главная кнопка стала прямоугольной и цельной: **«Смена окончена»**.
- Добавлен мягкий узор на кнопке, без ощущения двух отдельных кнопок.
- Окно ввода времени закреплено снизу и открывается стабильнее на телефоне.
- Поля времени больше не стоят вплотную и не должны пересекаться.
- Начало смены по умолчанию всегда **10:00**, его можно изменить вручную.
- Конец смены для сегодняшнего дня ставится по текущему времени.
- Ячейки календаря стали шире визуально: меньше отступы, одинаковая сетка, выходные выделены красным.
- Обновлён service worker, чтобы GitHub Pages быстрее подтягивал свежую версию.

## Что умеет

- Ввод начала и окончания смены.
- Автоматический расчёт суммы за смену, за месяц и за всё время.
- Пустой календарь, который можно заполнять вручную.
- Загрузка графика из таблицы: Excel, CSV или JSON.
- Сохранение данных в браузере телефона через localStorage.
- Резервная копия данных в JSON.

## Как открыть

Открой `index.html` в браузере или загрузи проект на GitHub Pages.

## Что заменить на GitHub

Лучше заменить все файлы из папки проекта:

- `index.html`
- `styles.css`
- `app.js`
- `manifest.webmanifest`
- `service-worker.js`
- `README.md`
