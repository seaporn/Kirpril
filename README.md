# Мои смены

Компактное приложение для учёта смен и зарплаты.

## Что изменено в этой версии

- Главная кнопка переименована в **«Смена окончена»** и сделана объёмной.
- Окно ввода времени открывается аккуратнее и больше не фокусирует поле автоматически.
- Главный экран стал компактнее.
- В календаре суббота и воскресенье выделены красным.
- Все ячейки календаря одинакового размера, длинный текст не растягивает колонки.
- На главном экране оставлены только главные суммы: месяц и всего.
- Если загружен график, дополнительно показывается план месяца.

## Что умеет

- Ввод начала и окончания смены.
- Автоматический расчёт суммы за смену, за месяц и за всё время.
- Пустой календарь, который можно заполнять вручную.
- Загрузка графика из таблицы: Excel, CSV или JSON.
- Сохранение данных в браузере телефона через localStorage.
- Резервная копия данных в JSON.

## Как открыть

Открой `index.html` в браузере или загрузи проект на GitHub Pages.

## Как загрузить график из Excel

1. Открой приложение.
2. Нажми ⚙.
3. В разделе **График из таблицы** проверь имя сотрудника.
4. Укажи стандартное время для смен из графика.
5. Нажми **Загрузить график** и выбери `.xlsx` файл.

Приложение ищет строку сотрудника и дни, где в таблице стоят отметки смен.

Важно: импорт Excel использует библиотеку SheetJS через CDN. На GitHub Pages это работает при наличии интернета. CSV и резервная копия JSON могут загружаться без этой библиотеки.
