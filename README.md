# Мои смены

Компактное PWA-приложение для учета смен, графика и зарплаты. Работает в браузере, хранит данные на устройстве через `localStorage` и может устанавливаться на телефон как обычное приложение.

## Возможности

- Быстрая запись смены кнопкой **Смена окончена**.
- Начало смены по умолчанию: **10:00**.
- Окончание смены подставляется по текущему времени.
- Расчет суммы за день, месяц и весь период.
- План месяца из Excel, CSV или JSON.
- Резервная копия данных в JSON.
- Защита от битых данных и старых форматов хранения.
- Безопасный вывод данных без вставки пользовательского HTML.
- Service Worker для работы на GitHub Pages и базового офлайн-кэша.

## Файлы проекта

```text
index.html            Разметка приложения
styles.css            Визуальный стиль и адаптивность
app.js                Логика учета смен, импорта и настроек
manifest.webmanifest  Настройки PWA
service-worker.js     Кэш приложения
README.md             Описание проекта
```

## Как запустить локально

Открой папку проекта через локальный сервер. Например:

```bash
python3 -m http.server 8080
```

Потом открой в браузере:

```text
http://localhost:8080
```

## Как загрузить на GitHub Pages

Загружай в репозиторий именно файлы проекта, а не zip-архив:

- `index.html`
- `styles.css`
- `app.js`
- `manifest.webmanifest`
- `service-worker.js`
- `README.md`

Дальше включи GitHub Pages:

```text
Settings → Pages → Deploy from a branch → main → /root → Save
```

## Формат CSV для импорта смен

Минимальный вариант:

```csv
Дата;Начало;Конец;Ставка
2026-05-20;10:00;22:00;350
```

Поддерживаются русские и английские заголовки: `дата/date`, `начало/start`, `конец/end`, `ставка/rate`.
